# stepik_auto_test_course

Домашние задания курса **«Автоматизация тестирования с помощью Selenium и Python»** на Stepik.

## Модуль 2 — Полезные методы Selenium

В папке [`module_2`](module_2) собраны решения практических задач второго модуля:

| Файл | Тема |
|------|------|
| `2.1.5.py` | Работа с чекбоксами и радиокнопками |
| `2.1.6.py` | Получение значений атрибутов элементов |
| `2.2.3.py` | Работа с выпадающим списком (`select`) |
| `2.2.6.py` | Выполнение JavaScript и прокрутка страницы |
| `2.2.8.py` | Загрузка файла на страницу |
| `2.3.4.py` | Переключение на alert и обратно |
| `2.4.6.py` | Переключение между окнами браузера |
| `2.5.8.py` | Явные ожидания (`WebDriverWait`) |

## Запуск

Для запуска примеров нужны Python 3, Selenium и установленный geckodriver:

```bash
pip install selenium
python module_2/2.5.8.py
```

Каждый скрипт открывает учебную страницу, выполняет задание и выводит результат в консоль.
